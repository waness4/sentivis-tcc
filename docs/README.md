# Documentação acadêmica do SentiVis

Esta pasta separa materiais de escrita acadêmica, planejamento, apresentação e referências bibliográficas do código-fonte do sistema.

- `artigo/versoes_anteriores/`: cópias dos manuscritos do TCC enviados anteriormente. **Não presumir que sejam as versões finais ou que reflitam o estágio atual do código.**
- `planejamento/`: anteprojeto original.
- `apresentacao/`: apresentação acadêmica em PDF (versão enviada anteriormente).
- `referencias/`: documentos de apoio e inventário de literatura. **Artigos de terceiros em PDF devem permanecer em `referencias/pdfs/`, fora do Git.**

O protocolo científico e o histórico de experimentos devem sempre indicar a versão do texto e a versão do código utilizadas. Não copiar resultados de programas exploratórios como evidências científicas validadas.
